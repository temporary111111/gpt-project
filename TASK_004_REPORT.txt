ERRORS OR WARNINGS
==================
1. AMP non-finite gradient events: during the production run the gradient norm became inf 12 times (steps 8022, 8666, 8705, 12326, 15272, 15723, 20461, 24346, 25781, 30882, 35160, 37216). Root cause: GradScaler scale doubles every 2000 clean steps, so scale grows unbounded (65536 -> 1,048,576+), and rare fp16 overflow events become more likely; single-step replays of a failing step are not reproducible (non-deterministic).
2. The first two such events (steps 6144 and 8022) occurred BEFORE the fix and tripped the TASK 003.5 hard-stop guard (worked as designed; latest.pt preserved). After diagnosis, the guard was refined (implementation-engineer decision, documented here for the lead architect): a non-finite GRADIENT norm now skips the optimizer step, halves the AMP scale, drops grads, logs a warning + metrics record, and training continues; a non-finite LOSS remains a hard stop. This supersedes the TASK 003.5 hard-stop-on-inf-grad behavior; no hyperparameters or architecture were changed. All 12 events self-healed; no artifacts in the learning curve.
3. Brownout (power cut) interrupted the run at ~step 26,800; resumed cleanly from latest.pt (step 26,500) with identical hyperparameters — resume verification passed (step/tokens/best_val_loss continuity), no corruption, no .tmp leftovers.
4. Minor: a few generated samples contain "�" replacement characters where the vocabulary has no token for rare symbols (e.g., en-dashes in name lists). The tokenizer was trained on the cleaned corpus; this is a tokenizer/vocab coverage note, not a training defect.
