VALIDATION DATA FIX
  - --data uses data/processed/train.bin (100%, no internal split).
  - --val-data uses data/processed/validation.bin (100%).
  - test.bin is never touched by the trainer.

ROPE FIX
  - rotate_half() follows the two-halves convention
    (out = [-x[D/2:], x[:D/2]]).
  - _build_rope_cache now builds freqs = cat((freqs, freqs), dim=-1) so angle i
    is applied to BOTH halves of the same coordinate pair. The previous
    repeat_interleave layout paired mismatched coordinates.
  - Proved with the old layout: max norm deviation 9.5e-1 vs 4.8e-7 fixed.
  - tests/test_rope.py covers: position-0 identity, L2 norm preservation,
    hand-computed tiny vector (head_dim=4, t=1), model cache layout,
    Q/K same-frequency-convention symmetry, and causality (future tokens do
    not change earlier outputs, dropout=0). The norm, tiny-vector, and cache
    layout tests FAIL under the old implementation (verified).

AMP
  - Correct flow: scaler.scale(loss/accum) -> backward -> scaler.unscale_ ->
    clip_grad_norm_ -> scaler.step -> scaler.update. Without AMP the same
    clip/step path runs without the scaler.
  - Gradient norm is logged every interval (grad_norm).

GRADIENT FIX
  - Non-finite train loss is checked per micro-batch BEFORE backward; a safe
    stop saves the latest healthy checkpoint and exits with [FATAL].
  - Non-finite gradient norm is detected after unscale; same safe-stop path.
  - Loss is accumulated over grad_accum micro-batches and divided before
    backprop, giving correct gradient magnitudes under grad-accumulation.

OPTIMIZER VALIDATION
  - configure_optimizer builds two groups: weight-decay on all matrices and
    embeddings, no decay on biases / norms / 1-D params.
  - Tied lm_head/tok_emb parameters are deduplicated by id (no double update).
  - Assertion guarantees every unique trainable parameter is in EXACTLY one
    group (covered by tests/test_train.py::test_optimizer_groups_cover_each_parameter_once).
  - Params: 29,270,528 total and trainable (8 layers, d_model 512, 8 heads,
    FFN 2048, context 256, vocab 8000). Architecture unchanged.
